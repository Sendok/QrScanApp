# **App Name**: ScanX

## Core Features:

- Responsive Design: Mobile-first design optimized for QR code scanning on various devices.
- Camera Overlay: A camera view with a cosmetically designed overlay for clear scanning feedback.
- Scan Interface: Dedicated 'Scan' tab/screen for initiating QR code scans.
- Scan History: A 'History' tab/screen to view past scanned QR codes and their associated data.
- AdMob Integration: Integration of AdMob to display ads after every three scans.

## Style Guidelines:

- Primary color: Soft lavender (#D0BFFF) for a calm, modern feel.
- Background color: Very light lavender (#F5F0FF) to provide a soft, unobtrusive backdrop.
- Accent color: Pale blue (#ADD8E6) to complement the lavender and highlight interactive elements.
- Body and headline font: 'Inter' sans-serif for a clean, readable, modern UI.
- Simple, minimalist icons to represent scan actions and history.
- Clean, mobile-optimized layout using Shadcn UI components for a consistent and user-friendly experience.
- Subtle animations for transitions and feedback to enhance the scanning experience.
